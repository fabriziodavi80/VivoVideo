# VivoVideo

Editor video personale per Android, pensato per un solo telefono (vivo X300 Ultra).
Kotlin + Jetpack Compose + Media3 (Transformer, Effect, ExoPlayer).

## Installare l'ultima versione

Dal telefono apri:
**https://github.com/fabriziodavi80/VivoVideo/releases/latest/download/VivoVideo.apk**

Ogni modifica al ramo `main` viene compilata automaticamente da GitHub Actions
e pubblicata come nuova release. Tutte le versioni sono firmate con la stessa
chiave, quindi si installano sopra la precedente.

## Stato

Fase 1 – prova tecnica: import di un video, filtri colore GPU, velocità
costante e speed ramp, export H.265/H.264 fino al 4K con encoder hardware,
salvataggio in `Film/VivoVideo`.
